算法是解决问题的有限步骤集合，复杂度用大 O 记号衡量。

常见时间复杂度（从快到慢）：
O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)

基础数据结构：
- 数组：随机访问 O(1)，插入删除 O(n)
- 链表：插入删除 O(1)，访问 O(n)
- 栈：后进先出，push/pop 均 O(1)
- 队列：先进先出，enqueue/dequeue 均 O(1)
- 哈希表：平均 O(1) 查找，最坏 O(n)
- 二叉搜索树：平均 O(log n)，退化为链表时 O(n)
- 堆：取最值 O(1)，插入删除 O(log n)

排序算法：
- 冒泡排序 O(n²)
- 插入排序 O(n²)，小数组性能好
- 归并排序 O(n log n)，稳定，需额外空间
- 快速排序 平均 O(n log n)，最坏 O(n²)
- 堆排序 O(n log n)，原地
- 计数/桶/基数排序 O(n)，需特定条件

搜索算法：
- 线性搜索 O(n)
- 二分搜索 O(log n)，要求有序
- 深度优先搜索（DFS）：栈实现
- 广度优先搜索（BFS）：队列实现
- A* 启发式搜索
- Dijkstra 最短路径 O((V+E) log V)

动态规划：将问题分解为重叠子问题，用备忘录避免重复计算。
典型问题：背包、最长公共子序列、编辑距离。

贪心算法：每步选局部最优，适用于拟阵结构问题。
分治算法：分解、解决、合并，如归并排序、快速排序。
